# Coco Jar — Site de prezentare (MVP)

Site simplu, static (HTML + CSS + JS), optimizat pentru conversie locală:
- call-to-call
- click WhatsApp
- meniu zilnic
- pagină evenimente + catering
- formular de cerere ofertă

### Structură
- `index.html`
- `meniu.html`
- `meniu-zilei.html`
- `despre-noi.html`
- `evenimente-catering.html`
- `contact.html`
- `styles.css`
- `scripts/site.js`
- `data/` (config + meniuri)
- `robots.txt`, `sitemap.xml`

Date editabile:
- `data/site-config.json`
- `data/meniu-zilei.json`
- `data/meniu-complet.json`
